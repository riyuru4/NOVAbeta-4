NOVA Chromebook対応版

元のNOVAデザインを残しながら、Chromebookの横長画面・タッチ操作・キーボード操作に合わせて調整しています。

変更点:
- Chromebook/PCでは横幅を広く使い、リンクカードを多列表示
- タブレット・スマホでは画面幅に合わせて列数を調整
- タッチ端末では編集・削除ボタンを常時表示
- キーボードの / キーで検索欄にフォーカス
- フォーカス時の視認性を改善

使い方:
GitHub Pagesの公開元にある index.html を、この版の index.html で置き換えてください。
このファイルはWebサイト版です。サイト側のiframe埋め込み拒否を解除するものではありません。
